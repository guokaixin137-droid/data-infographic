# 从公开作品取得配色

在内容主线确定后查色。先用用户明确要求的色值、品牌手册或视觉参考。用户指定部分颜色时，可为其余角色寻找相容用色。只用公开的主题词、博主名或已知公开账号检索，私有正文、访问令牌和分享链接留在项目内。

## 怎么查

- **具名创作者或品牌**。先用账号、官网链接或作品名核对身份。检索“名字 + 官网 / 作品集 / brand colors / media kit”。打开本人发布的主页、近期系列封面、代表作品或视觉规范。比较跨作品反复出现的背景、前景和强调色，避开承载平台的界面颜色。如果创作者有多个系列，优先参考与本题对应的系列。
- **只有主题**。用主题词、受众和内容形态组合搜索，例如“城市骑行 年报 信息图”或“urban cycling data report charts”。选与主题贴近的几个不同发布者，实际查看图表页、公开报告或专题图解。记录相似色在图里的用途，剔除广告、单张照片色调和同一作品的转载。只有一个相关样本时，称其为本图的视觉参考。多家配色各异时，选最适合信息结构的一种，并限定观察范围。
- **如何取色**。官网明确给出的 HEX 或可核对的样式色值可以准确引用。从图中取色时看成片的填充、标题、图例或同一系列重复出现的颜色。记录页码、元素和用途，区分“规范值”“作品取样”“为对比度调整”。文字搜索摘要不足以判断实际颜色时打开原页面、公开样式或图表。有图就看图。
- **访问受限或依据不足**。优先使用用户提供的参考。仍无可用线索时用易读的默认色或自行配色，并在交付说明中写明依据。不要把推断写成品牌官方色或整个领域的流行度排名。

## 怎么用

从观察中给纸色、正文深色、图表主色、重点强调色和负值色分配角色。让同一含义跨章节、语言和输出格式保持一致。深底上的亮黄可以用在关键数字，浅底图形可采用有足够对比度的深色。用标签、正负号或位置辅助辨识。查色与排版通常由 Agent 一次完成。

随附渲染器接受可选的 palette。colors 包含 paper、ink、primary、accent、negative 五个 #RRGGBB 色值。渲染器会在文字或数据标记与底色过于接近时调整明暗。矩阵数字沿用纸色或墨色，中间色阶有需要时略调底色，使数字对比度达到 4.5:1。references 接受有 label、url 和可选 note 的数组，显示在成品末尾的“配色参考”中。可用 heading 本地化该标题。由资料导出的事实仍放在顶层 sources。色值随 HTML 写入，离线导出可以复现。

例如，为与 Wes Bos 的 Cobalt2 作品相关的图解配色时，作者公布的深蓝和黄色可直接用作主题依据。下面的浅底由制图者选定，负值色在作品粉色基础上加深以便在纸色上辨识。[作者对 Cobalt2 的介绍](https://wesbos.com/uses) · [作者公布的色表](https://github.com/wesbos/cobalt2-vscode#colours)

~~~json
{
  "palette": {
    "colors": {
      "paper": "#FAF8F0", "ink": "#122738", "primary": "#1F4662",
      "accent": "#FFC600", "negative": "#A91455"
    },
    "references": [{
      "label": "Wes Bos · Cobalt2",
      "url": "https://github.com/wesbos/cobalt2-vscode#colours",
      "note": "取其深蓝和黄色。浅底及负值粉色为本图的可读性调整。"
    }]
  }
}
~~~

实际项目重新检索相应的主题或创作者。向读者交代最有代表性的原页及采用方式，保留紧凑版面。
